# Die Page Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add an observer-facing die page: the Viewer, opened from a `view=die` link, showing only the live 3D die, the top-face number and a status dot. The Sender gets a `Viewer | Die` switch that picks which page its QR code and link open.

**Architecture:** The die page is the existing Viewer mode in `index.html`, with three additions:
- `state.diePage` set from the URL.
- A `data-page="die"` attribute on `#app-shell`, so CSS can hide everything except the stage.
- Observer wording for the status pill.

The die model is forced without being saved. The Sender's `buildPairingUrl` gains a `view=die` parameter, driven by a remembered switch.

**Tech Stack:** One static `index.html` (CSS, markup, one inline script), no build step. Tests: `tests/harness.test.js` (Node `vm`, fake DOM, mock Supabase), run with `npm test`.

**Spec:** `docs/superpowers/specs/2026-11-24-die-page-design.md`

## Global Constraints

- Keep one static file with no build step. Don't add a `die.html` or a shared `.js` file.
- Write user-visible strings with `textContent`, never `innerHTML`.
- Never put a secret key into `localStorage`, a QR code or a link. All key checks go through `validateCredentials`, which is unchanged.
- No protocol or payload changes. The Sender sends exactly what it sends today.
- The normal Viewer must look and behave exactly as before, including its pill wording and its saved Phone / Die choice.
- Update `README.md` in the same change, as CLAUDE.md requires.
- Run `npm test` before every commit. Don't push: pushing to `main` deploys.
- Exact copy:
  - die page status words: `Live`, `Connecting…`, `Waiting for the die`, `Weak signal`, `Signal lost`
  - die page tab title: `Die`
  - share title for the die link: `Die`
  - switch labels: `Viewer`, `Die`

## Review Focus

1. **A real QR scan.** Credentials arrive in the hash, and scrubbing them must keep `view=die` in the address bar. Test: Task 2, booting the die page from the Sender's actual QR text, hash included.
2. **`view=die` with a missing or malformed room** (`?view=die`, `?room=ab&view=die`). The normal app should open, not a blank die page. Test: Task 1.
3. **The Sender taps New while Die is selected.** The QR code should follow the new room and still open the die page. Test: Task 2.
4. **A die link without credentials, on a phone with nothing saved.** Only the settings show. After Save & Apply, the page joins the room and the settings hide again. Test: Task 1.
5. **A phone that opened the die page later opens a normal Viewer link.** It should show its own saved model (phone by default), because the die page never saved `die`. Test: Task 1.

```js
{
  const server = createServer();
  const store = new Map([['gyrolink_supabase_url', 'https://abc.supabase.co'], ['gyrolink_supabase_anon_key', ANON]]);
  const t = boot({ server, store, share: true });
  await t.els['btn-choose-sender'].fire('click');
  const room = t.text('s-room-code');
  const lastQr = () => t.qr[t.qr.length - 1] || '';
  const pressed = () => `${t.els['btn-link-viewer'].attrs['aria-pressed']},${t.els['btn-link-die'].attrs['aria-pressed']}`;
  check('sender QR opens the Viewer by default', pressed() === 'true,false' && !lastQr().includes('view=die'), lastQr().slice(0, 60));
  await t.els['btn-link-die'].fire('click');
  check('Die switch: QR opens the die page with credentials', pressed() === 'false,true' && lastQr().includes(`?room=${room}&view=die#u=`) && lastQr().includes('k=') && store.get('gyrolink_sender_link') === 'die', lastQr().slice(0, 60));
  await t.els['btn-copy-link'].fire('click');
  check('Die switch: Share Link shares the die link titled Die', t.shares[0] && t.shares[0].url === lastQr() && t.shares[0].title === 'Die', JSON.stringify(t.shares[0]).slice(0, 80));

  // Scanning that QR code: the hash is scrubbed, view=die stays, the Sender counts it
  const u = new URL(lastQr());
  const d = boot({ server, store: new Map(), search: u.search, hash: u.hash });
  await sleep(150);
  check('scanned die QR opens the die page and joins', d.els['app-shell'].dataset.page === 'die' && d.location.search === `?room=${room}&view=die` && d.location.hash === '' && d.text('health-badge-text') === 'Connected', `${d.location.search} ${d.text('health-badge-text')}`);
  check('sender counts the scanned die page', t.text('s-viewers') === '1', t.text('s-viewers'));

  t.els['chk-include-creds'].checked = false;
  await t.els['chk-include-creds'].fire('change');
  check('die link without credentials', lastQr() === `https://example.com/?room=${room}&view=die`, lastQr());
  t.els['chk-include-creds'].checked = true;
  await t.els['chk-include-creds'].fire('change');

  await t.els['btn-new-room'].fire('click');
  await sleep(300);
  const room2 = t.text('s-room-code');
  check('New keeps the die link on the new room', lastQr().includes(`?room=${room2}&view=die#`), lastQr().slice(0, 60));
  await d.els['btn-viewer-back'].fire('click');
  await t.els['btn-sender-back'].fire('click');

  const t2 = boot({ store });
  await t2.els['btn-choose-sender'].fire('click');
  const lastQr2 = () => t2.qr[t2.qr.length - 1] || '';
  check('die link choice is remembered on reload', t2.els['btn-link-die'].attrs['aria-pressed'] === 'true' && lastQr2().includes('&view=die'));
  await t2.els['btn-link-viewer'].fire('click');
  check('Viewer switch goes back to the Viewer link', store.get('gyrolink_sender_link') === 'viewer' && !lastQr2().includes('view=die'));
  await t2.els['btn-sender-back'].fire('click');
}
```
